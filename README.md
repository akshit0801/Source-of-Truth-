# SKAI Space · Shared Source of Truth

The SKAI Space master deck, shared between ConveGenius and Chrysalis: the pitch, financial model, operating model, curriculum design and market positioning.

## Open it

Open `index.html` in a browser. Use **Back** / **Next** (or the arrow keys) to move between slides, and **Present** for full screen. The section tabs at the top jump to each section.

To host it, enable GitHub Pages on this repository (Settings → Pages → deploy from the `main` branch, root folder).

## Files

| File | What it is |

| `index.html` | The deck (cover plus 24 slides) |
| `mission-map.html` | Interactive Mission Map, embedded on the Mission Map slide |
